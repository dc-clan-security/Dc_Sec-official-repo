# 🚀 はじめに

Dc_Sec をサーバーに導入する手順と、権限システムの仕組みを説明します。

## 1. Bot を招待する

招待URL（README 参照）から Bot をサーバーに追加します。

- **管理者 (Administrator) 権限を推奨します。** バックアップ復元・Nuke 排除・ログ取得には、ロール/チャンネル/Webhook/監査ログ/キック/BAN の広範な権限が必要です
- **Bot のロールはできるだけ上位に置いてください。** Bot より上位のロールのメンバーは、Bot がキック・処罰・復元の対象にできません
- 権限を絞る場合は最低限: `ロールの管理` `チャンネルの管理` `メンバーをキック/BAN` `メッセージの管理` `監査ログの閲覧` `タイムアウト` `Webhookの管理` `絵文字の管理`

## 2. 初期設定（最初の10分）

サーバーに入れたら、まず以下を設定します。すべてスラッシュコマンドで完結します。

| 手順 | コマンド | 内容 |
|---|---|---|
| ① | `/log channel <#ch>` | ログの送信先を設定（参加・退出・削除・BAN等の記録） |
| ② | `/log events` | 記録するイベントの種類を選択 |
| ③ | `/modrole add <ロール>` | Dc_Sec のコマンドを実行できるモデレーターロールを登録 |
| ④ | `/security spam` `/security raid` 等 | スパム・レイド対策を調整（既定値でも動作します） |
| ⑤ | `/backup setup` | 自動バックアップの間隔と backuplogs チャンネルを設定 |
| ⑥ | `/security honeypot <#ch>`（任意） | 罠チャンネルを1つ作ると荒らしを高精度で自動排除できます |

コミュニティ機能（ウェルカム `/welcome setup`、レベル `/level reward`、認証 `/webauth setup` 等）は [コマンドリファレンス](commands/README.md) を参照してください。

## 3. 権限システムの仕組み（コマンドゲート）

Dc_Sec では、**すべてのスラッシュコマンドに共通の権限ゲート**が適用されます。

### 一般ユーザーが使えるのは「自分に関するコマンド」だけ

- ✅ 残高確認 (`/coin balance`)、お題抽選 (`/topic random`)、ブックマーク、誕生日登録、カジノ、トリビア、天気、スナイプ 等
- ❌ 他のユーザーに影響するコマンド（BAN・警告・設定変更・パネル作成等）はすべて**モデレーター権限が必要**

モデレーターとは、次のいずれかに該当する人です:

1. `/modrole add` で登録されたモデレーターロールのメンバー
2. Discord 権限「サーバーを管理」を持つ人
3. サーバーオーナー、Bot を追加した人

さらに一部のコマンド（経済の付与・お題の自動投稿設定等）は「サーバーを管理」権限が必要です。各コマンドの必要権限は [コマンドリファレンス](commands/README.md) の「実行権限」列をご確認ください。

### 連投対策（レート制限）

- すべてのコマンドに最小2秒のクールダウンがあります（コマンドごとに個別設定あり）
- 公開コマンド: 10秒に5回を超えると警告、繰り返すと10分間のタイムアウト
- 権限のないコマンドの連打: 30秒に10回で無音化 + タイムアウト

これはコマンド連投スパムと、Bot アカウントのレート制限（API 制限）の両方を防ぐための仕組みです。

## 4. Web ダッシュボード

`/mod secstatus` に表示される URL から、Discord アカウントでログインできる Web ダッシュボードを利用できます。

- サーバー設定（ログ/スパム/レイド/プレフィックス）の編集
- バックアップの作成・ダウンロード・復元・削除
- Anti-Nuke の閾値・処置・発動履歴
- コンテンツフィルターの詳細設定

（管理権限を持っているサーバーのみ表示されます）

## 5. 用語集

| 用語 | 意味 |
|---|---|
| **Dcelia** | Dc_Sec 内の通貨。メッセージやゲームで獲得でき、ショップ・ロール自販機で使う（換金不可） |
| **Nuke** | 短時間でチャンネル・ロールを大量削除するなどしてサーバーを破壊する行為 |
| **Anti-Nuke** | Nuke を検知して実行者を排除し、バックアップから自動復元する機能 |
| **ハニーポット** | 一般メンバーには見えない罠チャンネル。ここに投稿＝攻撃者と確定して自動処置 |
| **backuplogs** | バックアップファイルを投稿・保管するチャンネル。`.json` を投稿すると手動復元も可能 |
| **ストライク制** | 違反の累積に応じてタイムアウト→警告→自動BANと段階的に処罰する仕組み |

## 6. トラブルが起きたら

- **Bot がオフライン**: `/status` のパネルで稼働状況を確認できます（VPS ごとの停止は外部ハートビートで検知）
- **コマンドが実行できない**: 権限ゲートに引っかかっている可能性があります（上記「権限システム」参照）。連投しすぎた場合は10分ほど待ってください
- **誤BANされた**: `/mod case` でケースを確認し、モデレーターに `/mod untimeout`・解除を依頼してください
- その他は [よくある質問](faq.md) へ

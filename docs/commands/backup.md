# 💾 バックアップ・復元

[← コマンド一覧に戻る](README.md)

サーバーのロール（権限/色/位置）・チャンネル（権限上書き/トピック/カテゴリ）・絵文字・スタンプ・BANリスト・メンバーのロール・サーバー設定に加え、Dc_Sec 各機能の設定データ（スティッキー/レベル/チケット等）を1つの JSON ファイルとして保存・復元します。Anti-Nuke 発動時の自動復元にも使われます。

## `/backup`

**バックアップ操作**

自動バックアップの間隔設定、Cloudflare R2 へのクラウド保存 (`cloud` / `cloudpull`)、backuplogs チャンネルへの `.json` / `.json.gz` 投稿による手動復元に対応しています。復元は「ID一致 → 名前一致 → 新規作成」の順で行われ、メッセージ履歴とスレッドは対象外です。大きなサーバーの復元は Discord のレート制限により数分かかることがあります。

| コマンド | 説明 | 実行権限 | 引数 |
|---|---|---|---|
| `/backup setup` | backuplogs を作成し、最初のバックアップを取得します | Mod以上 | — |
| `/backup settings` | 設定データ(sticky/レベル/チケット等)のみをバックアップ/復元します | Mod以上 | `mode` (任意) |
| `/backup create` | 今すぐバックアップを作成 | Mod以上 | — |
| `/backup list` | 保存済みバックアップ一覧 | Mod以上 | — |
| `/backup restore` | バックアップから復元(バックアップに無いチャンネル/ロール/絵文字/スタンプは全て削除) | Mod以上 | `name` (任意)<br>`bans` (任意) |
| `/backup delete` | バックアップを削除 | Mod以上 | `name` (必須) |
| `/backup interval` | 自動バックアップ間隔と保持数 | Mod以上 | `minutes` (必須)<br>`keep` (任意) |
| `/backup cloud` | クラウド退避 (R2) の状態とバックアップ一覧 | Mod以上 | — |
| `/backup cloudpull` | クラウドからバックアップをローカルへ取得 | Mod以上 | `name` (必須) |

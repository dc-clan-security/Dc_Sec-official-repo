# 🔨 モデレーション・ログ

[← コマンド一覧に戻る](README.md)

警告・タイムアウト・キック・BAN といった制裁と、各種イベントログの設定を行います。制裁はすべて自動連番のケース番号で記録され、`/mod case` で照会できます。

## `/mod`

**モデレーション (警告/制裁/ケース/権限/ロックダウン)**

処罰はケース番号付きでデータベースに記録されます。`/mod secstatus` で Dc_Sec 全体の設定状況を、`/mod lockdown` で全チャンネルを一括ロックできます。`/mod role`・`/mod owner` はコマンド実行権限の管理、`/mod accessinfo` はユーザーがどのコマンドを使えるかの確認です。

| コマンド | 説明 | 実行権限 | 引数 |
|---|---|---|---|
| `/mod warn` | メンバーを警告します | Mod以上 | `member` (必須)<br>`reason` (任意) |
| `/mod warnings` | メンバーの警告履歴を表示します | Mod以上 | `member` (必須) |
| `/mod clearwarnings` | メンバーの警告を全て削除します | Mod以上 | `member` (必須) |
| `/mod timeout` | メンバーをタイムアウトします | Mod以上 | `member` (必須)<br>`minutes` (必須)<br>`reason` (任意) |
| `/mod untimeout` | タイムアウトを解除します | Mod以上 | `member` (必須) |
| `/mod kick` | メンバーをキックします | Mod以上 | `member` (必須)<br>`reason` (任意) |
| `/mod ban` | メンバーをBANします | Mod以上 | `member` (必須)<br>`reason` (任意)<br>`delete_days` (任意) |
| `/mod case` | モデレーションケースを照会 (番号指定で詳細/無指定で一覧) | Mod以上 | `case_id` (任意)<br>`member` (任意)<br>`limit` (任意) |
| `/mod secstatus` | Dc_Secの設定状況とダッシュボードURL | Mod以上 | — |
| `/mod lockdown` | 全テキストチャンネルの発言を一括ロック/解除 | Mod以上 | `mode` (必須) |
| `/mod role` | モデレーターロールを設定します | Mod以上 | `role` (必須) |
| `/mod owner` | オーナーロールを設定します(設定後はロックされ Bot追加者/サーバーオーナーのみ変更可) | Mod以上 | `role` (必須) |
| `/mod accessinfo` | このサーバーの権限設定(Bot追加者/ロール)を表示します | Mod以上 | — |

## `/log`

**ログの送信先とON/OFFの設定**

メンバー参加/退出・メッセージ削除/編集・BAN・ボイス入退室・チャンネル/ロール変更などのイベントログの送信先と対象を設定します。

| コマンド | 説明 | 実行権限 | 引数 |
|---|---|---|---|
| `/log channel` | 一般ログの送信先チャンネルを設定します | Mod以上 | `channel` (任意) |
| `/log security` | セキュリティログの送信先チャンネルを設定します | Mod以上 | `channel` (任意) |
| `/log events` | 一般イベントログのON/OFF | Mod以上 | `enabled` (必須) |
| `/log status` | ログ設定の現在状態を表示します | Mod以上 | — |
| `/log test` | テストログを各送信先に流して配信を確認します | Mod以上 | — |

## `/snipe`

**スナイプ (削除/編集/リアクション解除の履歴)**

削除・編集・リアクション解除された直近のメッセージを復元表示します（一般開放）。APIキーを含むメッセージは復元されません。

| コマンド | 説明 | 実行権限 | 引数 |
|---|---|---|---|
| `/snipe message` | このチャンネルで直近に削除されたメッセージを表示します (◀▶で履歴) | 一般 | — |
| `/snipe edited` | このチャンネルで直近に編集されたメッセージを表示します (◀▶で履歴) | 一般 | — |
| `/snipe reaction` | このチャンネルで直近に取り消されたリアクションを表示します | 一般 | — |

### d! プレフィックスでも実行可能

| コマンド | 使い方 |
|---|---|
| `d!ban` | `d!ban <@ユーザー\|ID> [削除する日数 0-7] [理由]` |
| `d!unban` | `d!unban <ユーザーID> [理由]` |
| `d!kick` | `d!kick <@ユーザー\|ID> [理由]` |
| `d!mute` | `d!mute <@ユーザー\|ID> <時間 10m/2h/1d> [理由]` |
| `d!unmute` | `d!unmute <@ユーザー\|ID>` |
| `d!purge` | `d!purge <件数 1-100> [@ユーザー\|ID]` |
| `d!slowmode` | `d!slowmode <秒>` |
| `d!lock` / `d!unlock` | チャンネルのロック/解除 |
| `d!help` (`d!h`) | 全コマンド一覧/詳細 |

`d!` はサーバーのカスタムプレフィックス設定後も常に使用できます。実行には対応する Discord 権限が必要です。

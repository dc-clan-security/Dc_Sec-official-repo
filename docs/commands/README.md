# 📖 コマンドリファレンス

Dc_Sec の全スラッシュコマンド **269個**（コマンドグループ 56個 + 単発 4個）を種類別に説明します。各コマンドの **実行権限** は以下の3種類に分類されます。

| 権限 | 意味 |
|---|---|
| 一般 | すべてのサーバーメンバーが実行できます |
| サーバー管理 | Discord の「サーバーを管理」権限が必要です |
| Mod以上 | Dc_Sec のモデレーター権限（モデレーターロール所属 または サーバー管理権限）が必要です |

この権限分類はサーバー設定でさらに強めることができますが、緩めることはできません。

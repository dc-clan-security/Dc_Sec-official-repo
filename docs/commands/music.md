# 🎵 音楽機能

[← コマンド一覧に戻る](README.md)

`d!` プレフィックスで動作する音楽プレイヤーです。YouTube の URL または検索ワードで再生します。サーバーのカスタムプレフィックスを変更しても、音楽コマンドは常に `d!` で使用できます。

| コマンド | 動作 |
|---|---|
| `d!play` / `d!p` | YouTube URL または検索ワードで再生（自動入室・移動）。検索は TOP20 をセレクトメニューで選択 |
| `d!join` / `d!j` | ボイスチャンネルに参加 |
| `d!leave` / `d!l` | 退出（キュー破棄） |
| `d!skip` / `d!s` | 現在の曲をスキップ（一時停止中も可） |
| `d!queue` / `d!q` | キュー表示 |
| `d!pause` / `d!resume` | 一時停止 / 再開 |
| `d!volume` / `d!v` | 音量 0〜200%（引数なしで現在値） |
| `d!mhelp` / `d!mh` | 音楽コマンド一覧 |
| `d!omikuji` | おみくじ |
| `d!miq` | 引用カード生成（対象メッセージへの返信 + 本文 `miq` でも可） |

- 60秒間ボイスチャンネルに人がいなくなると自動退出します。
- `miq` 引用カード: 引用したいメッセージに返信して `miq` と送ると、投稿者の画像と本文のカード画像を生成します（黒/白・モノクロ切替ボタン付き）。
- 音声は yt-dlp + ffmpeg で処理します。初回再生時に実行体をダウンロードするため、最初の1曲だけ時間がかかることがあります。
